# Limit Service

REST микросервис для управления дневными лимитами платежей пользователей.

## Функциональность

- Хранение дневных лимитов платежей для каждого пользователя (по умолчанию 10000.00)
- Автоматический сброс лимитов в 00:00 каждого дня
- Уменьшение лимита при успешном платеже
- Восстановление лимита при отмене/откате платежа
- Автоматическое создание лимитов для новых пользователей

## API Endpoints

### Получение лимита пользователя
```
GET /api/limits/{userId}
```

### Обработка платежа (уменьшение лимита)
```
POST /api/limits/payment
Content-Type: application/json

{
  "userId": 1,
  "amount": 1000.00
}
```

### Восстановление лимита
```
POST /api/limits/{userId}/restore?amount=1000.00
```

### Ручной сброс дневных лимитов
```
POST /api/limits/reset
```

## Запуск

1. Запустите базу данных:
```bash
docker-compose up postgres-limit -d
```

2. Запустите приложение:
```bash
mvn spring-boot:run -pl limit-service
```

Приложение будет доступно на порту 8082.

## Конфигурация

Основные настройки в `application.yml`:
- Порт сервиса: 8082
- База данных: PostgreSQL на порту 5433
- Дневной лимит по умолчанию: 10000.00

## База данных

Используется PostgreSQL с автоматическими миграциями через Liquibase:
- Таблица `user_limits` для хранения лимитов
- Автоматическое создание начальных записей для пользователей 1-5
- Индексы для оптимизации запросов
